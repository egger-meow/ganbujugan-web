> 1. 本專案所有吉祥物插畫、狀態圖與貼圖皆為第一方品牌正式資產，**嚴禁**使用 AI 假造替代貓咪、替換成 Emoji、以 CSS 重新手繪或任意破壞角色設定。

## 六、前端渲染與效能準則

1. **透明邊緣處理**：透明 PNG 均採無損萃取，背景採用米白色 `#FAF9F6` 或翡翠淺底 `#D1FAE5`，不應出現白框或黑邊鋸齒。
2. **尺寸與防破版**：所有 `<img>` 標籤皆嚴格標注真實 `width` 與 `height`，並搭配 `object-fit: contain`，防止頁面載入時發生排版位移 (Cumulative Layout Shift, CLS)。
3. **優先順序加載**：首頁 Hero 區塊的吉祥物採 Eager loading，其餘視窗下方之教學圖與狀態圖一律採 `loading="lazy"` 與 `decoding="async"`。
